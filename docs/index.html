A coding agent for the model on your own machine.

flywheel is a small terminal agent written in C, tuned for Qwen3.8-27B on Apple Silicon. It works with any OpenAI-compatible endpoint.

The harness does the work a small model can't

Local models fail in repetitive, recoverable ways: malformed tool calls, doom loops, silent stalls. flywheel handles them around the model.

Loop breaker

Spots repeated and near-repeated commands, prunes them, injects a correction and nudges temperature.

Strict tool calls

Repairs common JSON slips in shell commands. Truncated arguments are rejected, never run.

Structured edits

write_file and edit_file with unique-match replacement, confined to the project.

Verification gate

Type checks and compiles per language, then one requirement-by-requirement pass before finishing.

Live terminal UI

Type while it works, Esc to interrupt, collapsible output, streaming markdown, tokens per second.

Small and static

About 6k lines of C. libcurl only on macOS; the Linux build is a static binary with no dependencies.

Safety, stated plainly

flywheel runs shell commands on your machine. Here is what it does and does not protect against.

  • Asks before anything outside a short read-only list; chaining, redirection, expansion and write flags always prompt.
  • The approval dialog shows the whole command, with control and invisible characters made visible.
  • Keys typed before the dialog appears are ignored. Permission rules shipped inside a repository are not trusted.
  • One-shot and bench modes approve automatically. Deny rules are best-effort. This is not a sandbox: run untrusted work in a container.

Get started

macOS on Apple Silicon, with clang and libcurl.

git clone https://github.com/megasoft1978/flywheel
cd flywheel && make

./flywheel setup   # optional: engine + model, asks first
./flywheel init    # per-project instructions
./flywheel         # interactive session
