FLYWHEEL.

The agent harness measured against its model, not the market.
Pure C. Single binary. Built for local models on Apple Silicon.

GitHub Quickstart

Why a harness for this model?

Mainstream agent CLIs are prompted, tooled and tested around frontier cloud models. Point them at a local 27B and you get malformed tool calls, doom loops and silent stalls. At this scale harness quality is half the product — flywheel is built around that truth: every compensation exists because a benchmark failure demanded it.

The compensation layer

Loop breaker

Period-1/2/3 + similarity detection prunes doom loops, injects corrective context, escapes on a temporary temperature shift.

Lenient tool parsing

Repairs truncated JSON, raw control chars, missing braces — small models get a target they can actually hit.

Structured file tools

write_file / edit_file with path confinement and unique-match edits. No more heredoc roulette.

Verify gates

Per-language auto-verification (tsc, compileall, go vet) every few write-turns and before finishing.

Permission system

y / always / never per command prefix, persisted across sessions. Deny rules for destructive commands always win.

Pure C, zero-dep static

No node, no python, no runtime. The Linux build is a fully static binary that speaks HTTP/SSE over raw sockets — it runs in bare containers. Starts in milliseconds.

A professional TUI

Input that never dies

Type while the agent works — Enter queues, Esc interrupts, scrollback stays anchored instead of yanking to bottom.

Markdown native

Headings, bold/italic, fenced code boxes, tables, clickable OSC-8 hyperlinks — rendered as you stream.

Collapsible everything

Tool output and thinking collapse to one-liners. Click or ^O to expand. Mouse wheel scrolls.

Live telemetry

tok/s, context gauge, spinner phases, session stats, completion pills — the cockpit a local model deserves.

Benchmark-driven

Every harness change is validated against a 13-task TypeScript/React suite (express APIs, schedulers, SQLite repos, optimistic-update UIs, type-level gymnastics). Best composite:

Terminal-Bench 2.0 — the public scoreboard

Terminal-Bench 2.0 is harness-agnostic: the agent runs inside Linux Docker containers, end-state tests score the task. flywheel enters through a Harbor custom agent — the static binary is uploaded into each container and talks back to the Splash engine on the host. Quickstart

# build — needs clang + libcurl, nothing else
git clone https://github.com/megasoft1978/flywheel
cd flywheel && make

# point it at any OpenAI-compatible engine
./flywheel setup

# then just talk to it
./flywheel
